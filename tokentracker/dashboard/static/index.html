How the cost is calculated

Every request is priced at Anthropic's published list prices, so the total is what the same tokens would cost on the Claude API. It is not a bill. A Pro or Max subscription has no per-token charge, and API customers with negotiated or Batch rates pay less.

For one request the formula is:

input tokens × input rate
+ output tokens × output rate          (thinking tokens count as output)
+ cache-read tokens × cache-read rate
+ 5-minute cache writes × 1.25 × input rate
+ 1-hour cache writes × 2 × input rate

Fast mode uses its own rates. Claude Haiku 5.5 uses higher rates when a prompt (input plus cache reads and writes) is over 100,000 tokens. US-only inference costs 1.1×. Each web search adds $0.01. The token counts come from the API's own usage object on every response, which is what Anthropic bills.

When Cline or Hermes report a cost themselves, that figure is used instead of the table. A model with no rate card, such as a local model, is unpriced: its requests count toward tokens but not toward cost.
